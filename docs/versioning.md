# Compatibility and versions

The website version is owned by `package.json`; `package-lock.json` is generated by npm. The chart has its independent version in `Chart.yaml`. The Flutter artifact has its own reviewed client commit and checksummed manifest; bridge version 1 is a separate compatibility contract. Equal version numbers are not a compatibility check.

The initial website candidate is `0.1.0-dev.0`. No release or tag is created here. A website-only layout change need not change the gameplay contract. An incompatible bridge requires an explicit bridge/version migration on both sides and browser acceptance before a new artifact is pinned.
